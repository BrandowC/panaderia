# Ruta de implementación

## Entrega 1 — Fundamentos
Proyecto, estilo base, Supabase, migraciones, seed, CI y entorno validado.

## Entrega 2 — Seguridad
Login, perfiles, roles, rutas, RLS y pruebas negativas de autorización.

## Entrega 3 — Productos
Administración, archivo lógico, búsqueda, orden y auditoría.

## Entrega 4 — Conteo móvil
Borradores, cantidades, autosave, recuperación local y finalización segura.

## Entrega 5 — Reportes
Snapshot, enlace público, PDF, compartir, WhatsApp, correo y revocación.

## Entrega 6 — Producción
E2E, accesibilidad, rendimiento, documentación y despliegue.

## Evolución opcional
Extraer un backend NestJS solo si aparecen integraciones complejas, múltiples clientes, varios canales, alta carga, colas, procesos largos o una API consumida por aplicaciones adicionales.
