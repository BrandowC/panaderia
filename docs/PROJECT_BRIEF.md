# Alcance del producto

## Problema
El conteo de productos elaborados se realiza de forma manual y resulta difícil consolidarlo, conservarlo y compartirlo rápidamente con el dueño de la panadería.

## Solución
Aplicación web móvil que presenta el catálogo de panes, permite registrar cantidades, guarda un borrador y genera un reporte público, fechado e inmutable.

## Usuarios
- Administrador o propietario.
- Empleado encargado del conteo.
- Revisor externo que recibe el enlace público, sin cuenta.

## Dentro del MVP
- autenticación;
- dos roles;
- catálogo de productos;
- conteos con autosave;
- historial;
- reporte público;
- PDF;
- compartir enlace;
- auditoría básica;
- diseño móvil.

## Fuera del MVP
- ventas y caja;
- precios y costos;
- recetas;
- materias primas;
- proveedores;
- facturación;
- pagos;
- WhatsApp Business API automática;
- aplicaciones móviles nativas;
- inteligencia artificial.

## Métricas iniciales
- finalizar un conteo de 30 productos en menos de 5 minutos;
- cero pérdida de cantidades ante recarga accidental cuando existe borrador local;
- máximo tres interacciones para compartir el reporte;
- todos los recorridos críticos cubiertos por E2E.
