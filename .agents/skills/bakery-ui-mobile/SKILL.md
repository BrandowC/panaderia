# UX móvil para conteos

- Diseña primero para 320–430 px.
- Mantén nombre y cantidad visibles sin desplazamiento horizontal.
- Usa inputs numéricos grandes y objetivos táctiles mínimos de 44 px.
- Minimiza tecleo y evita modales innecesarios.
- Muestra guardado, error, sin conexión y recuperación de borrador.
- Incluye búsqueda y categorías sin ocultar productos accidentalmente.
- Usa paleta cálida de panadería y contraste AA.
- No dependas del color para comunicar estados.
- Prueba teclado móvil, zoom, orientación y contenido largo.
- Revisa que finalizar el conteo sea deliberado y que compartir requiera pocos pasos.
